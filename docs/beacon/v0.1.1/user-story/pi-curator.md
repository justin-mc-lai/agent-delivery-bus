# User Story: pi-curator (v0.1.1)

**Canonical truth**: [../features/pi-curator/truth.md](../features/pi-curator/truth.md)

## 旅程

1. 定时 tick 或用户指令触发 `adb curator tick`。
2. 对 approved 提案构建知识检索请求（anchors）。
3. 宿主 agent（pi）回填选题卡。
4. `adb curator apply` 校验后写回 personal-brain ideas/。
5. ledger 落账，创作链可检索。
